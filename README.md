# 筱葳學測公民

2027 學測社會科「公民與社會」的 14 週學習地圖與線上教材。從 `index.html` 進入。

- 課程脈絡：一個問題串起四大塊（人與社會、民主政治、法律、經濟），兩條貫穿線（權利與權力、效率與公平）；每個單元開頭標出「承接・本週・接到」，結尾列出在別週還會出現的概念
- 作答技能：情境題判讀四步驟、混合題作答法
- 人與社會、民主政治、法律、經濟共 12 個單元教材（比較表、判斷示範、附解析練習，共 100 題）
- 公民概念速查：62 個高頻概念，每個可點開看小學生也懂的白話解釋與「名稱怎麼記」，附易混淆對手，可遮住解釋自我測驗
- 主題串連：電價、外送員、都更、假訊息、少子化與跨科題組
- 歷屆試題紀錄、錯題本

學習進度與作答紀錄只存在各自裝置的瀏覽器裡。法規以現行條文為準。
