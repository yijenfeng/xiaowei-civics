混合題作答法

第 2 週起。學測社會有混合題，包含簡答、填表與圖表判讀。公民最常考「寫出概念＋套進情境說明理由」，只寫名詞拿不到滿分。

這一節回答一個問題：「簡答題要寫到什麼程度，才算答得完整？」

PART 2 ・ 答題公式

概念＋判準＋情境證據

題目
某校規定：上課使用手機一次，直接記大過。請以比例原則判斷此規定是否妥當。
寫法範例得分
只寫名詞「違反比例原則。」只有結論，判準與證據都沒寫
只抄情境「因為記大過太重了。」沒有連到概念的判準
完整「不妥當（立場）。比例原則的必要性要求在同樣有效的手段中選侵害最小者（判準）；學校可先口頭警告或暫時保管手機，就能維持上課秩序，直接記大過侵害過大（證據）。」完整
寫完檢查三件事：有沒有寫出概念名稱？有沒有寫出判準？有沒有用到題目給的材料？
PART 3 ・ 圖表題

讀圖表三步：讀標題單位 → 描述變化 → 連概念

  1. 讀標題單位看清楚是「比例」還是「人數」、是「名目」還是「實質」
  2. ↓
  3. 描述變化用「由……上升到……」「差距擴大」寫出趨勢，引用 1–2 個數字
  4. ↓
  5. 連概念例如吉尼係數上升 → 所得分配趨於不平均 → 可能需要重分配政策
練習

動手試試看

選擇題點選答案、簡答題按「對答案」，作答紀錄會保留在這台裝置。
Q1混合題問：「請說明材料中工廠排放廢水屬於何種概念，並說明理由。」哪一個答案最完整？
看解析
C。這個答案同時寫出概念名稱、判準（第三人受損、未反映在價格）與材料證據。
Q2寫「立場論證」題時，下列何者最不恰當？
看解析
D。立場題要立場明確。正反都寫會讓答案自相矛盾。
Q3表格顯示某國吉尼係數由 0.32 上升到 0.38，最適合的描述是？
看解析
B。吉尼係數介於 0 到 1，愈大代表所得分配愈不平均。它不直接表示成長率或失業率。
Q4某校規定：上課使用手機一次，直接退學。請用比例原則判斷是否妥當，並寫出理由。
看參考答案與解析

不妥當。比例原則要求手段必要、侵害最小，且損害不能大於利益；學校可用警告、保管手機等較輕手段維持秩序，退學剝奪受教育權，損害遠大於維持上課秩序的利益。

寫出「必要性」或「衡量性」其中之一並連到情境即可，兩個都寫更完整。

系統只檢查是否寫到關鍵詞：不妥 / 違反 / 不合 / 不符　必要 / 最小 / 過大 / 損益 / 衡量 / 相當（每組至少寫到一個）。寫得通順、因果清楚才是得分關鍵，請對照參考答案。

Q5某市公車票價被政府凍漲在 15 元多年，業者因虧損減少班次，尖峰時段常擠不上車。請用供需概念解釋。
看參考答案與解析

凍漲等於價格上限，而且低於均衡價格；在這個價格下業者願意提供的服務量減少，乘客需要的量卻較多，需求量大於供給量，形成短缺（擠不上車）。

關鍵是「價格上限低於均衡 → 短缺」這條鏈。

系統只檢查是否寫到關鍵詞：上限 / 管制 / 低於 / 凍漲　短缺 / 供給量 / 供不應求 / 不足（每組至少寫到一個）。寫得通順、因果清楚才是得分關鍵，請對照參考答案。
